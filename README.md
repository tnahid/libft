Description:

The goal of Libft is to recreate a selection of useful functions and build them into a reusable static library named libft.a.
Libft provides implementations of common character-checking, string, and memory-manipulation functions, along with basic conversion and allocation functions.
Writing these functions helps develop a stronger understanding of pointers, arrays, memory, strings, and C library behavior.

Instructions:

Run make from the root of the repository to compile the source files and create libft.a.
The Makefile uses the compiler flags -Wall -Wextra -Werror.
Include libft.h in your C source file and link your program against libft.a.

Resources:

Unix manual pages, such as man strlen, man memcpy, and man memmove.
C library documentation provided by the system toolchain.
The 42/1337 Libft subject and project requirements.
AI tools were used as a learning aid to clarify C concepts and reason about edge cases and test cases.
